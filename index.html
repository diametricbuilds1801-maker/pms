Google Sheet sync

One-time setup: paste Code.gs as a standalone Apps Script project, run authorize() once, deploy as a Web App ("Anyone" access), and paste the deployment URL above. Nothing is created on the Sheet until you click "Create project" — after that, "Auto-sync" (if ticked) pushes shortly after every change, plus every 10 seconds on its own regardless, so anything not yet synced always catches up on its own within a few seconds — no need to re-edit a field to get it to save. The same button turns into "Sync now" for an immediate manual push. This way, typing a placeholder name or just trying the tool out doesn't spawn a real Google Sheet by itself. This tool no longer auto-loads from the Sheet on its own (that used to risk overwriting newer edits sitting only in this browser) — use "Reload from Sheet" above whenever you deliberately want the Sheet's copy instead. This same URL works for every project — each gets its own Sheet, auto-created inside a fixed Drive folder and auto-shared as "anyone with the link can view." Daily follow-up

Assign each task to a half-day shift. Follow-up owner is fully automatic and cannot be overridden: the EA follows up new/on-track tasks, and the process coordinator handles any delayed (overdue) task. Site supervisor pre-fills from the Summary team list; override per task if needed.

Material & resource readiness — next 7–10 days

To be filled by the person managing the project. For every task starting soon, confirm all three — Drawings, Material and Labour — before the task is released. Work shall not start on a task until all three are confirmed, so material reaches on time and resources are managed for a seamless flow into the next task.

Milestones

A milestone is a zero-duration marker (no duration of its own) placed on a specific date — it doesn't get typed in directly. Instead, pick which task it follows (its predecessor); the milestone's date is automatically set to that task's planned finish date, and updates on its own whenever that task's schedule shifts. It shows up on the Gantt chart as a small diamond marker alongside the tasks.
